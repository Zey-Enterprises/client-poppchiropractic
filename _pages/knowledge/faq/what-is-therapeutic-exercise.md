The practice describes therapeutic exercise as one part of care. Examples include resisted movements, stretching, balance exercises and changes to positions used in daily life. Scott’s list includes work directed at particular spinal segments as well as exercises involving larger movements. Which task he chooses depends on what he is trying to work on.

The method page describes manual work in the office. The exercise library provides a separate set of references with photos, diagrams and movement sequences. An illustration can help you remember which exercise you were shown. The fact that the practice publishes an exercise does not mean it is part of everyone’s care.
